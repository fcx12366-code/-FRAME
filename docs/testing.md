## 单元测试范围

26 项单测覆盖恶意 URL、伪域、非 HTTPS、凭据、异常端口、开放重定向参数，视频域和路径限制；API 记录的电影与剧集规范化，不将未知 API 字段当作播放权或演职员事实；真实 TMDB 请求参数、四秒超时、网络及 schema 失败回退、本地优先去重。另覆盖组合搜索筛选、免费入口所需核实证据、损坏或受限 localStorage、收藏去重、进度形状与有限数字、同页面与跨标签通知，以及 React 外部存储快照引用稳定性。

观看进度用例以 DOM 模拟 `currentTime`、`duration` 与 `timeupdate`，仅验证应用持久化逻辑。媒体错误用例明确使用 `page.route(...).abort()` 注入失败，仅验证错误界面。这两类证据均不作为实际影片播放成功的依据。

来源核验记录显示，三部官方视频的字幕列表为空；浏览器可用的字幕轨另记录于最终 `textTracks` 字段。本站没有额外新增中文字幕。本轮没有进行整部影片播放验收、声音试听、字幕翻译质量或不同地区和运营商的网络可用性验收；也没有把官方外链可打开等同于所有地区都能免费完整播放。

## 测试修正历史

首轮将 2023 年动画筛选误当作空态，实际存在《放手一飞》；改为 2012 年的确实无匹配组合。首轮原生播放器坐标点击命中了进度条，没有启动媒体，相关结果保留为失败尝试，没有作为连通性证据。

产品随后增加明确的“开始放映”按钮，真实播放测试改为点击这个用户可见按钮。另一轮测试暴露三处测试预期需要更新：持久化观看记录标签页使宽泛的“观看记录”定位匹配到清空按钮；首页两个主按钮使样式定位不唯一；官方入口采用 `/videos/watch/` 路径，旧测试只接受 `/w/`。已改为精确语义定位、刷新后 URL/选中态断言和受信任官方路径校验，定向复测通过，再执行一次完整最终回归。

早期原始报告保留在 `playwright-results.round1.json`、`playwright-results.round2.json`、`playwright-results.selectors-rerun.json` 与 `video-results.round1.json`；最终验收以无后缀原始报告和 `final-summary.json` 为准。
