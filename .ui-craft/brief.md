# 1. Product purpose

FRAME 帮助中国大陆影迷发现真实作品、保存片单，并区分授权站内播放、官方入口、试看和不可免费观看。

# 2. Primary user

晚间用桌面或手机找片的大陆影迷，需要先感受电影，再快速确定在哪里合法观看。

# 3. Principles

1. 播放状态必须有证据，未知不写免费。
2. 一张值得停留的画面，比十张重复卡片有效。
3. 编辑推荐、专题、片库各有不同密度与版式。
4. 本地内容先呈现，外部网络失败不能阻断找片。
5. 用户主动开始播放；收藏不要求登录。

# 4. Success

用户能从首页进入详情，了解来源并播放授权短片或访问官方平台；也能搜索和保存稍后观看片单。

# 5. Out of scope

- 登录、后端数据库、付费或破解资源。
- 本轮任何部署、自动部署流程及 Netlify 连接。
- 未明确许可的第三方 iframe 和受保护视频地址提取。

# 6. Learned constraints

- 2026-10-30：用户已给定炭黑、暖白、克制沙金、现代中文字体、低动效；无需重复询问。图像与品牌素材不可混用。保留配色，UI UX Pro Max 的通用紫蓝配色和营销转化布局不适用。

# 7. Composition

- 首页：full-bleed-overlay，由用户明确要求的电影宽幅主视觉决定；电影主体置右，下左信息。移动端图像与文字上下编排。
- 列表：紧凑筛选栏和多列片架，详情：宽幅画面＋独立信息/来源双栏。
- Signature：FRAME 画幅角标和策展刊物编号，仅在实际专题/编辑序列中使用。
